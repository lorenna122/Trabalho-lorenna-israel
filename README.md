Site sobre Dyllan Johnny - Site de fã

Trabalho desenvolvido em HTML cru, sobre o criador de conteúdo brasileiro Dyllan Johnny. O site aborda sua trajetória, rotina, literatura, relação com Freud, curiosidades e outros temas, organizados em múltiplas páginas navegáveis.

Estrutura de pastas
projeto/
├── html/     → todas as páginas .html do site
├── img/      → imagens usadas nas páginas 
├── audio/    → arquivos de áudio 
└── video/    → arquivos de vídeo 

Páginas do site
inicio.html — Página inicial
quem-e.html — Quem é Dyllan Johnny
carreira.html — Carreira e trajetória
youtube.html — O canal e os "Papinhos Furados"
relacao-freud.html — Sua relação com Freud
literatura.html — Literatura e o livro "O Pássaro Morto"
rotina.html — Rotina do criador de conteúdo
redes-sociais.html — Presença em outras redes sociais
curiosidades.html — Curiosidades gerais
muaythai.html — A prática do Muay Thai
influencialeitura.html — Influência na leitura
quiz.html — Formulário interativo com perguntas sobre o conteúdo

Todas as páginas compartilham o mesmo menu de navegação no cabeçalho, permitindo acesso direto a qualquer parte do site a partir de qualquer página.

Tecnologias utilizadas
HTML5 semântico (header, nav, main, article, section, figure, footer, entre outras)
Elementos de mídia nativos (audio, video)
Formulário com diversos tipos de campo (text, email, date, radio, range, color, file, datalist, details)
Sem CSS e sem JavaScript — o projeto tem foco exclusivo em HTML cru
